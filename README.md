Jingler
This is a project zomboid mod for build 42 which adds immersive key jingle sounds. The more keys you carry, the faster you move, the louder the jingle. Jingles will attract zombies so stash them in a bag to muffle the noise. 

## Features

- Dynamic jingles based on the number of keys carried.
- Volume scales with movement type: walking, running, or sprinting.
- Muffling effect when keys are stored in containers like backpacks.
- Randomized jingle variations for auditory diversity.

## Installation

1. Download or clone this repository.
2. Place the `Jingler` folder into your `Zomboid/mods/` directory.
3. Enable the mod in the in-game Mods menu. ([Project Zomboid Build 42 Modding Template - GitHub](https://github.com/LabX1/ProjectZomboid-Build42-ModTemplate?utm_source=chatgpt.com))
